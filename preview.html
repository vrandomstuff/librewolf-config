Tokyo Night Storm

Deep storm-blue chrome, lavender text and neon accents. The theme keeps the browser quiet so the page stays the brightest thing on screen. 

// tokyo-night-storm.css
:root {
  --tn-bg: #24283b;
  --tn-bg-highlight: #292e42;
  --tn-fg: #c0caf5;
  --tn-accent: #7aa2f7;
}
